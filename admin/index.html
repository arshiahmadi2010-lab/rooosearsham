تصاویر سایت

عکس‌های ثابت صفحه اصلی و صفحات داخلی را آپلود، جایگزین، حذف و اندازه‌گذاری کنید.

هر جایگاه یک تصویر مشخص دارد. اگر تصویری برای یک جایگاه ثبت نشود، طراحی پیش‌فرض سایت حفظ می‌شود.

ناماسلاگ

چیدمان بخش‌های صفحه اصلی

با دکمه‌های بالا/پایین ترتیب نمایش بخش‌ها در صفحه اصلی را تغییر بده.

    نقشه و لینک‌های تماس

    لینک Embed نقشه، لینک باز کردن نقشه و شبکه‌های اجتماعی را بدون دست‌کاری کد مدیریت کن.

    CSS اختصاصی

    دستت کاملاً بازه — هر CSS دلخواهی رو اینجا بنویس تا مستقیم روی سایت اعمال بشه. اگه با CSS آشنا نیستی، از این بخش صرف‌نظر کن.

    پشتیبان‌گیری از تنظیمات

    یک نسخه پشتیبان از تمام متن‌ها، رنگ‌ها و تنظیمات سایت بگیر، یا نسخه قبلی را برگردان.
